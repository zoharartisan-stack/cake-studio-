# Illustrations

Empty-state and spot illustrations. The files here are **custom,
brand-matched placeholders** authored in the CakeCraft palette (Cream /
Gold / Rose / Chocolate).

The free libraries suggested in the plan — [unDraw](https://undraw.co) and
[Storyset](https://storyset.com) — deliver assets through their web export
UIs rather than a clean direct-download URL, so drop-in replacements are
added manually: export as SVG, recolor to the brand palette, and save here.
